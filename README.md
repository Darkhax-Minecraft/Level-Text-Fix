<!-- description-start -->
This is the official GitHub repo for the LevelTextFix mod. Fix issues related to level text, and adds acessibility options. You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/level-text-fix) or [Modrinth](https://modrinth.com/mod/level-text-fix). Please report issues [here](https://github.com/Darkhax-Minecraft/Level-Text-Fix/issues).
<!-- description-end -->

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.leveltextfix', name: 'leveltextfix-neoforge-26.1.2', version: '26.1.2.0'
     // Fabric
     implementation group: 'net.darkhax.leveltextfix', name: 'leveltextfix-fabric-26.1.2', version: '26.1.2.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.leveltextfix', name: 'leveltextfix-common-26.1.2', version: '26.1.2.0'
}
```
